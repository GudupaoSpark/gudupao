# Gudupao 官方网站

## 项目介绍

Gudupao（古都炮）是一家专注于创新技术解决方案的科技公司。本项目是公司官方网站，使用 Nuxt 3 构建，集成了国际化、响应式设计和现代 Web 技术。

## 技术栈

- Nuxt 3
- Vue 3
- TypeScript
- Tailwind CSS
- i18n 国际化
- Sitemap 生成

## 功能特点

- 响应式设计
- 中英文双语支持
- SEO 优化
- 现代化页面交互
- 模块化架构

## 本地开发

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 目录结构

- `components/` - Vue 组件
- `layouts/` - 页面布局
- `locales/` - 国际化语言文件
- `pages/` - 页面组件
- `public/` - 静态资源
- `server/` - 服务端插件

## 部署

项目可以部署到支持 Node.js 的静态站点托管服务，如 Vercel、Netlify 或自建服务器。
